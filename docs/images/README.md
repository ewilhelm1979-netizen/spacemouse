# Documentation image provenance

`spacemouse.png` is an AI-assisted documentation image based on the tested
3Dconnexion SpaceMouse Wireless BT hardware. `setup.png` is an AI-assisted
documentation rendering based on the tested Linux and Wine controller-
detection view. OpenAI tools substantially assisted with preparation.

These files are illustrative documentation visuals. Neither file is raw
private audit evidence, an untouched forensic screenshot, or an unaltered
product photograph. The repository's functional/security audit and
reproducible tests remain the authoritative technical evidence.

Runtime node numbers shown in the visuals are examples and must not be used to
infer or hardcode exact node numbers on another system. The human maintainer
reviewed and approved the images and remains responsible for their
publication.
